## Overview

This router handles Time-Based One-Time Password (TOTP) setup, storage, and verification.

### **Test Case 1: Generate TOTP Secret (Setup)**

This endpoint generates a new TOTP secret for initial setup. The secret should be used to generate a QR code for the authenticator app.

* **HTTP Method:** `GET`
* **Endpoint URL:** `http://localhost:8000/totp/setup`
* **Request Input:** None
* **Request Headers:**

  ```http
  Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
  ```

  * Requires a valid JWT access token from authentication. (check `auth_router.md` test cases)
* **Expected Successful Response (HTTP 200):**

  ```json
  {
    "totp_secret": "JBSWY3DPEHPK3PXP"
  }
  ```
* **Flow:** The returned `totp_secret` should be converted to a QR code by the frontend using a URI format like: `otpauth://totp/YourApp:user@example.com?secret=JBSWY3DPEHPK3PXP&issuer=YourApp`

---

### **Test Case 2: Verify and Store TOTP Secret**

This endpoint verifies that the user has correctly configured their authenticator app by validating the first TOTP code, then stores the TOTP secret in the database.

* **HTTP Method:** `POST`
* **Endpoint URL:** `http://localhost:8000/totp/store`
* **Request Input (Form Data):**

  ```json
  {
    "user_totp": "123456",
    "user_totp_secret": "JBSWY3DPEHPK3PXP"
  }
  ```

  * **`user_totp`**: The 6-digit TOTP code generated by the user's authenticator app.
  * **`user_totp_secret`**: The TOTP secret generated in Test Case 1.
* **Request Headers:**

  ```http
  Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
  Content-Type: application/json
  ```
* **Expected Successful Response (HTTP 200):**

  ```json
  {
    "message": "TOTP Secret stored in DB."
  }
  ```
* **Error Responses:**

  * **HTTP 401 Unauthorized**: If the TOTP code is invalid (handled internally in the verification logic).
  * **HTTP 500 Internal Server Error**: If database storage fails.

---

### **Test Case 3: Verify TOTP Code (Public Endpoint)**

This endpoint verifies a TOTP code against a user's stored secret, identified by their URL slug. This is typically used for upload verification.

* **HTTP Method:** `POST`
* **Endpoint URL:** `http://localhost:8000/totp/verify`
* **Request Input (Form Data):**

  ```json
  {
    "totp": "123456",
    "url_slug": "my_custom_endpoint"
  }
  ```
  * **`totp`**: The 6-digit TOTP code to verify.
  * **`url_slug`**: The user's unique URL slug that identifies their upload endpoint.
* **Request Headers:**

  ```http
  Content-Type: application/json
  ```
  * Note: This endpoint does NOT require authentication as it's used by external uploaders.
* **Expected Successful Response (HTTP 200):**

  ```json
  {
    "is_valid": true
  }
  ```
* **Error Responses:**

  * **HTTP 401 Unauthorized:**
    ```json
    {
      "is_valid": false
    }
    ```
  * **HTTP 500 Internal Server Error**: If database query fails or TOTP secret is not found.
